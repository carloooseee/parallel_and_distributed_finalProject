FINAL PROJECT PROPOSAL AND DEVELOPMENT GUIDELINES
I. Objectives:
• Identify a real-world problem that can benefit from parallel or distributed computing.
• Explain the importance of parallelism and distributed processing in solving
computational problems.
• Design an algorithm that utilizes parallel processing techniques.
• Develop a Python application using appropriate libraries for parallel or distributed
computing.
• Compare sequential and parallel execution in terms of processing time and
performance.
• Analyze the results using speedup, efficiency, and other relevant performance metrics.
• Present and defend the developed system, including its implementation and findings.
II. Description:
• Each group must select a real-world problem or scenario that can be addressed using
Parallel and Distributed Computing.
• Students are required to conduct a short research study and develop a working Python
application demonstrating at least one parallel or distributed computing technique.
• The application must include a comparison between sequential and parallel
processing to evaluate performance.
III. Requirements:
Each group must accomplish the following:
1. Research and Scenario
• Project title
• Background of the problem
• Problem statement
• Project objectives
• Proposed solution using PDC concepts
• Brief explanation of the parallel or distributed computing technique to be used
2. Python Program Development
The application must include:
• Working Python program.
• Sequential processing implementation.
• Parallel processing implementation.
• Appropriate use of Python libraries such as threading, multiprocessing, or concurrent.
• Display of program output.
• Execution time measurement.
3. Performance Evaluation
Students must compare sequential and parallel processing using:
• Execution time
• Speedup
• Efficiency (if applicable)
• Brief explanation of the results.

Grouping and General Guidelines
1. Each group must have 3–4 members only.
